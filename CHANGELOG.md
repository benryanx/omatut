# Changelog

All notable changes to OmaTut are documented here.

## v0.6.0-alpha.0 — 2026-09-04

First public alpha release.

- Screen-aware Omarchy guidance through the transparent shell overlay.
- Two-press voice flow with a desktop activation sound and local Voxtype transcription.
- Local learning journal with saved answers, steps, shortcuts, periodic observations, and recommended next topics.
- Tutor-provider choices: OpenAI, local Ollama, and OpenAI-compatible APIs.
- Optional OpenAI voice playback, independent of the selected tutor provider.
- Theme-aware companion UI, secure Secret Service credential storage, and opt-in history.

## Known limitations

- Tested on Omarchy 4.x only.
- Voice transcription depends on a working Voxtype and PipeWire installation.
- Ollama must have a vision-capable model installed before it can answer screen-aware questions.
- The installer is currently for Omarchy users; an AUR package is planned after alpha feedback.
