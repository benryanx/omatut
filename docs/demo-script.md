# OmaTut alpha demo — 40 seconds

Prepare a clean Omarchy desktop with the OmaTut companion open on **Home**. Use a harmless visible target such as the Omarchy menu, theme picker, or keybindings panel.

1. **0–4s — Set the scene**
   Show the desktop and say: “I’m building OmaTut: a screen-aware tutor for Omarchy.”
2. **4–9s — Ask naturally**
   Press `SUPER + SHIFT + T`. Let the ping and listening overlay appear. Ask one short question, for example: “How do I change my wallpaper?”
3. **9–19s — Teach on screen**
   Press the shortcut again. Show the playful processing state, then the guide bubble, target cue, answer, and shortcut.
4. **19–29s — Show that learning persists**
   Dismiss the guide with `ESCAPE`, return to the companion, and open **Learnings**. Show the saved question, answer, steps, and shortcut.
5. **29–37s — Show the companion’s value**
   Return to **Home** and point out the learning observation and next recommended Omarchy topic.
6. **37–40s — Close clearly**
   Say: “It’s open-source, local-first, and in alpha. I’m looking for Omarchy testers.”

Keep API keys, notifications, personal files, browser tabs, and private screenshots out of frame. Record at the display’s native scale; crop only after recording if needed.
